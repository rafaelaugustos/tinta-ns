# App capture

`tinta-ios.mp4` and its GIF preview show the actual app opening, Flow, the speed control, a color change and Touch in an iPhone 17 Pro simulator. Source: `f14180e`, Release, iOS 27.0. The capture was resized; video playback speed is unchanged. The app itself changes from 1× to 1.5× during the recording. The labels are live process readings during recording, not the standalone benchmark results.
